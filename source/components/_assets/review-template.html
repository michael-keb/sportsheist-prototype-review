What you're looking at

A standings screen for the tab that has no screens

Merits is the second of five navigation destinations. The other four are War Room, Backchat, Alerts and Profile — and of those, only War Room and Backchat have been designed. Merits, Alerts and Profile are currently places the navigation can take someone with nothing behind them.

This screen answers the question the tab implies: where do I stand, and who is ahead of me? It carries a personal standing summary, the top three, and a ranked list positioned so the viewer's own row is always identifiable.

Provenance

What is reused and what is new

Reused from the Figma file

  • Hero banner — field gradient, peak motif, prop-in-front layering
  • Tab bar — built from the four active-state frames
  • Section container — the Locker Rooms bordered wrapper
  • Status pill — the LIVE NOW treatment
  • Header pill — View all ↗
  • Photography — portraits and the athlete cutout, taken from the exports
  • Surfaces, radii, type scale — sampled, not approximated

New in this proposal

  • Standing summary card — rank, total, movement
  • Podium — top three, winner emphasised by scale and ring
  • Ranked row — index, club chip, movement indicator
  • Viewer's-row emphasis — accent wash and edge marker
  • Period control — Match / Week / Season

The hero prop is the centre figure from the Get Started group shot, isolated and converted to a cutout. It stands in for a purpose-shot object — Backchat has a microphone, War Room a helmet, so Merits should eventually have its own.

Decisions

Three things we need from you

  1. What is the currency called?

    The live build uses four names for one concept — Credits, Participation Credits, Participation Deposit and a legacy BOND. This screen calls it Merits to match the tab. Confirm, and we will use it everywhere.

  2. Are there tiers, or only ranks?

    The podium currently shows position only. If Merits is meant to carry standing over time — badges, levels, seasons that reset — that changes this screen and needs designing before build.

  3. Who should the hero object be?

    Every other tab banner has a purpose-shot prop. We can shoot or source one for Merits, or commit to figure-based cutouts across all five tabs.
