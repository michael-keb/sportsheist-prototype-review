Sorting

The segmented control the system already ships (.tax, results & actions), reused unchanged. It is chrome — it filters, it does not express an opinion — so it keeps the accent fill on its selected item. Nothing else on the screen does.

Newest · the default

Most recent top-level comment first. Replies always stay oldest-first inside their own thread, so an exchange still reads in the order it happened.

Oldest

The case as it was built. This is the order to read the day a vote closes, because it shows which argument came first and what answered it.

Most agreed

Ranked on agrees minus disagrees, not on agrees alone — otherwise a comment on 40 agree / 60 disagree outranks one on 30 / 2. Ties fall back to newest.

Pinned
A club comment marked pinned sits at the top in all three orders, and carries the Pinned by the club label so it is obvious it is exempt.
Not a vote
Most agreed re-orders the thread. It does not touch the ballot. The order of the discussion and the result of the vote are computed from different things and never appear in the same component.
Persistence
The choice is remembered per member, not per proposal — a member who reads most-agreed reads it that way everywhere.
